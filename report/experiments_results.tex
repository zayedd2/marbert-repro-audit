\subsection{Setup}
\label{sec:results-setup}

\paragraph{Runs.} We fine-tune MARBERT and AraBERT on three datasets with \rsNSeeds{} seeds
(\rsSeeds{}) under two protocols, giving \rsNRunsExpected{} runs; \rsNRunsDone{} completed. All runs
use the settings in Section~\ref{sec:method}. Training used \rsGPU{} and took
\rsGPUHours{} GPU-hours in total.

\paragraph{Protocols.} The \emph{historical} protocol follows [1]. It trains on the full training sets
(\rsNTrainHistArSarc{}, \rsNTrainHistAstd{} and \rsNTrainHistAjgt{} items for ArSarcasm-Sent, ASTD and
AJGT), scores the test set after every epoch and keeps the epoch with the best published metric on test.
The \emph{independent} protocol holds out a stratified \rsDevPct\% dev subset of each training set
(\rsNDevArSarc{}, \rsNDevAstd{} and \rsNDevAjgt{} items). The same subset is used for every model and
seed. It keeps the epoch with the best dev macro-F1, and the test set never influences selection.
Ties go to the earlier epoch. All metrics for a run are read from the same selected checkpoint.
Test sets are fixed (\rsNTestArSarc{}, \rsNTestAstd{} and \rsNTestAjgt{} items).

\paragraph{Uncertainty.} We keep two sources of uncertainty apart. \emph{Training randomness} is the
mean $\pm$ sample SD over seeds. Each MARBERT seed is paired with the AraBERT run of the same seed.
\emph{Finite-test uncertainty} is a 95\% paired percentile bootstrap over test items with \rsBootB{}
resamples. Each resample is applied to both models and all seeds, and we bootstrap the seed-averaged
difference. Following our proposal, a target counts as \emph{reproduced} if (i)~the gap to the
published score is at most \rsGapThreshold{}~pp, or the published score lies inside our seed range,
and (ii)~MARBERT still outscores AraBERT on that dataset.
